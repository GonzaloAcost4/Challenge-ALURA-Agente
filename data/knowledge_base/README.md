# Base de Conocimiento - ONE AI FOR TECH

Este directorio contiene la documentación oficial en formato **PDF** del programa **ONE AI FOR TECH (G10 2026)** de Oracle Next Education y Alura LATAM, incluyendo sus formaciones especializadas:

## Documentos del Programa
- `ONE_AI_for_Tech_G10_2026.pdf` - Visión general del programa y cronograma.
- `Nivelación.pdf` - Módulo de nivelación técnica.
- `Inteligencia de Datos y RAG Avanzado.pdf` - Formación en datos, embeddings y RAG.
- `Desarrollo y Orquestación con IA Generativa.pdf` - Formación en desarrollo con LLMs y LangChain.
- `Ingeniería de Agentes y Automatización.pdf` - Formación en agentes autónomos y n8n.
- `Oracle Cloud Infrastructure.pdf` - Formación en servicios cloud y despliegue en OCI.
- `Challenge Alura Agente.pdf` - Especificaciones del proyecto integrador.

## Instrucciones
1. Ejecuta `python create_sample_data.py` o presiona **"🔄 Indexar Documentos"** en la interfaz web de Streamlit para actualizar la base de conocimiento vectorial.
